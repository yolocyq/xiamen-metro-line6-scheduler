# 厦门地铁 6号线 · 智能排班系统（MVP）

基于你桌面《新建 XLSX 工作表.xlsx》（真实的 6 号线人工排班表）逆向建模的可运行网页应用。
纯前端（无需后端），可直接部署到 workbuddy.host，也支持本地双击 `index.html` 打开。

## 数据来源
- `parse_excel.py`：把你的 xlsx 解析为 `seed.json` / `seed.js`（17 个分区、323 人、11/01–11/08）。
- 分区：管理 / 参建人员 / 备班(48人) / 15 个车站（一农、林埭、鼎美、马銮中心、陈井、西滨、碑头、杏滨、内茂、董任、1号线官任、6号线官任、杏林湾、华侨大学）。
- 班次代号沿用原表：`R1 / KA1-1 / KB1 / KA2-1 / KA7-1 / KB2-1`。
- 备班派站写法沿用原表：`KA1-1（鼎美，替王文）`（去鼎美顶王文）。

## 对应你提的 4 大痛点
1. **资质未对接系统** → 系统记录每人 上岗证/消防证/电梯证/施工负责人证，顶替时校验资质，缺证即告警（顶替资质缺口）。
2. **休假多、变动大** → 「变动登记」勾选人员+休假类型+日期，一键「生成」自动找同岗合格人员顶替并标注「替X」。
3. **车站个性化要求** → 每站独立分区与编制，跨站抽人（正岗跨站）会单独告警提示本站空缺。
4. **无智能工时卡控** → 自动累计周期内工时，超 48h 标红预警（建议调休）。

## 核心逻辑（`engine.js`）
- **无变动一键确认**：你登记的变动与基础排班无差异时，直接沿用上次排班（原表），不重算。
- **顶替优先级**：同岗**备班** → 同站正岗 → 跨站正岗；多个备班用 Fisher-Yates **随机**抽取（符合你"更倾向于随机"）。
- **同角色硬约束**：站务员只顶站务员、行值↔行值、值站↔值站。
- **底板+增量**：以原表为底板，仅重排你实际改动的空缺，原表其余完全不动（验证：单处休假仅改动 2 个单元格）。

## 使用流程
1. 打开页面即呈现当前（原表）排班，可切到「人员管理」查看/调整每人性质（设为备班/恢复正岗）、所属站、资质。
2. 到「变动登记」：选人 → 选休假类型 → 勾日期 → 登记。
3. 点右上角「⚡ 生成 / 确认排班」→ 自动顶替 + 刷新排班总表与告警中心。
4. 「⬇ 导出」导出 CSV（Excel 可直接打开）。「↺ 重置示例」恢复初始数据。

## 11/08 之后怎么生成（周期延续）
原 Excel 只覆盖 11/01–11/08，所以系统默认只生成这 8 天。**11/08 之后的依据 = 把 11/01–11/08 当作一个轮班周期，按周期循环复用每个人的班次**（你选择的方案）。

- 点排班总表工具栏「📅 延续周期」→ 展开控制条。
- 选「延续 N 个周期（每周期 8 天）」→ 点「延伸并生成」。
- 两种复用模式（勾选框切换）：
  - **不勾选（默认，推荐）**：仅复用"班次旋转"（早/晚/休的节律），新周期从干净轮班开始；原表的休假/顶替标注不往前带（新周期的真实休假由你在「变动登记」重新登记）。
  - **勾选**：原样复用原周期的休假与顶替标注（含谁替谁），适合"完全照旧"的延续。
- 「回到原周期」一键还原到 8 天。
- 延伸后仍可像原周期一样：登记变动、自动顶替、导出 CSV（文件名自动带上新区间）。

## 部署到 GitHub Pages（得到公开网址）
本目录是**纯静态站点**（`index.html` + `app.js` + `engine.js` + `seed.js` + `styles.css`），可直接托管到 GitHub Pages。

1. 在 GitHub 新建一个仓库（例如 `line6-scheduler`）。
2. 推送本项目（已 `git init` 并提交，只需加远程并 push）：
   ```bash
   git remote add origin https://github.com/<你的用户名>/<仓库名>.git
   git branch -M main
   git push -u origin main
   ```
3. 仓库 → Settings → Pages → Source 选 **main** 分支 / **(root)** → Save。
4. 几分钟后访问：**https://\<你的用户名\>.github.io/\<仓库名\>/**
   （若仓库名是 `<用户名>.github.io`，则网址为 https://\<你的用户名\>.github.io/ ）

> 页面已加半透明水印「程有权　钱杨芯」，覆盖全站、不挡操作。

> 依据说明：引擎 `extendBase(employees, 模板日期, 新日期, {keepAnnotations})` 把第 k 个新日期映射到模板第 `k%8` 天，复制其班次；纯"被替"格（无自身班次）反推替班人当天班次，保证覆盖不漏。

## 接入你最新/真实数据
